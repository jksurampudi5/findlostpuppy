# Database & Data Model — FindLostPuppy 🐾

## Relational Schema

### 1. `users`
* `id` (UUID / string, Primary Key)
* `name` (string)
* `email` (string, Unique)
* `phone` (string, Optional)
* `created_at` (ISO timestamp)

### 2. `owner_profiles`
* `id` (UUID / string, Primary Key)
* `user_id` (Foreign Key -> `users.id`)
* `full_name` (string)
* `phone` (string)
* `email` (string)
* `address` (string, **STRICTLY PRIVATE**)
* `state` (string)
* `district` (string)
* `mandal_or_municipality` (string)
* `street_or_locality` (string)
* `pin_code` (string)
* `preferred_contact` (`phone` | `email` | `whatsapp`)
* `has_location_consent` (boolean)
* `latitude` (float, approximate)
* `longitude` (float, approximate)
* `approximate_area` (string, **PUBLIC SAFE REPRESENTATION**)
* `updated_at` (ISO timestamp)

### 3. `dogs`
* `id` (UUID / string, Primary Key)
* `owner_id` (Foreign Key -> `owner_profiles.id`)
* `name` (string)
* `breed` (string)
* `gender` (`Male` | `Female` | `Unknown`)
* `age` (string)
* `size` (string enum)
* `color` (string)
* `coat_description` (text)
* `distinguishing_marks` (text)
* `collar_info` (string)
* `microchip_id` (string)
* `temperament` (string)
* `medical_notes` (text)
* `primary_photo` (URL / base64 string)
* `photos` (array of URLs / strings)
* `created_at` (ISO timestamp)

### 4. `lost_reports`
* `id` (string, formatted e.g. `LOST-BRUNO-881`, Primary Key)
* `dog_id` (Foreign Key -> `dogs.id`)
* `owner_id` (Foreign Key -> `owner_profiles.id`)
* `owner_approximate_location` (string, safe)
* `last_known_location` (string)
* `last_known_latitude` (float, optional)
* `last_known_longitude` (float, optional)
* `date_lost` (date)
* `time_lost` (string)
* `additional_notes` (text)
* `status` (`LOST` | `SIGHTED` | `REUNITED` | `CLOSED`)
* `contact_mechanism` (JSON with visibility flags)
* `sighting_count` (integer)
* `created_at` (ISO timestamp)
* `updated_at` (ISO timestamp)

### 5. `sightings`
* `id` (string, Primary Key)
* `report_id` (Foreign Key -> `lost_reports.id`)
* `dog_name` (string)
* `date` (date)
* `time` (string)
* `location` (string)
* `photo` (URL / string, optional)
* `description` (text)
* `reporter_name` (string, optional)
* `reporter_phone` (string, **PRIVATE**)
* `reporter_email` (string, **PRIVATE**)
* `created_at` (ISO timestamp)
